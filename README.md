# Blinkit Grocery Data Analytics Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes Blinkit's sales data to uncover key insights regarding total revenue, customer ratings, item types, and outlet performance. It helps understand consumer behavior and business profitability.

## 🔑 Key Metrics Analyzed
* **Total Sales:** $1.20M generated across all outlets.
* **Items Sold:** 8,523 total items categorized.
* **Average Rating:** Strong customer satisfaction with a 3.92-star average rating.
* **Average Sales per Transaction:** $141

## 📈 Visual Insights Included
* **Fat Content Analysis:** Distribution of sales based on Low Fat vs. Regular products.
* **Item Type Breakdown:** Identification of top-performing grocery categories.
* **Outlet Performance:** Comparison of sales across different outlet sizes (Small, Medium, High) and location tiers.
* **Establishment Trends:** Tracking how sales evolved based on the outlet's establishment year.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop** for Data Visualization and Dashboard design.
* **DAX (Data Analysis Expressions)** for creating calculated metrics and KPIs.
* **Power Query** for data cleaning and transformation.
